ERA5

RasterDataSources.ERA5 — Type
ERA5{Provider<:ERA5Provider,Store<:ERA5Store,Product<:ERA5Product} <: RasterDataSource

ERA5 reanalysis: hourly, 0.25° (~31 km), 1940-present. Available as:

  • ERA5 or ERA5{Google,ARCO}: Google's public Zarr store, no account needed.
  • ERA5{ECMWF,ARCO} and ERA5{ECMWF,ARCO,Land}: ECMWF's Zarr stores.
  • ERA5{ECMWF,OnDemand} and ERA5{ECMWF,OnDemand,Land}: NetCDF downloads from the Climate Data Store API.

Layers use the CDS variable names, so they work with every provider, except:

  • Heights go last, e.g. :temperature_2m is CDS 2m_temperature.
  • :geopotential_at_surface is CDS geopotential.
  • :snow_depth_water_equivalent is ERA5's CDS snow_depth. Google also calls it snow_depth, and ERA5-Land calls it snow_depth_water_equivalent, all in metres of water equivalent. ERA5-Land has both, and its :snow_depth is in metres of snow.

See ARCO and OnDemand for usage.

ERA5Store

How ERA5 data is served, its second parameter: ARCO or OnDemand.

RasterDataSources.ARCO — Type
ARCO <: ERA5Store

Analysis-Ready, Cloud-Optimised Zarr stores, read remotely chunk by chunk rather than downloaded. getraster returns a CachedCloudSource to open with Zarr.jl, and layername(T, layer) gives the variable name in the store.

Google

ERA5 or ERA5{Google,ARCO}: Google's public ARCO-ERA5 store, no account needed. ERA5 only, ~3 month lag. See ARCO-ERA5. All layers are in one store.

getraster(ERA5{Google,ARCO})
using RasterDataSources, Zarr
source = getraster(ERA5)
store = Zarr.CachingStore(source.url, source.cache)
ds = zopen(Zarr.ConsolidatedStore(store, ""))
temp = ds[layername(ERA5, :total_precipitation)]

ECMWF

ERA5{ECMWF,ARCO} and ERA5{ECMWF,ARCO,Land}: ECMWF's stores, with no job queue (unlike OnDemand). Not guaranteed byte-identical to a CDS download. The CDS API token is sent as a Bearer header by the caller. Each store holds several layers, and only some ERA5 layers are available.

Warning

ECMWF describes ARCO access as a beta service. Licence: CC-BY.

getraster(T::Type{<:ERA5{ECMWF,ARCO}}, [layer]; chunking=:geo)

Arguments

  • layer: Symbol or Tuple of Symbol from layers(T), listed in ERA5.

Keywords

  • chunking: :geo (default, small area/long time) or :time (large area/short time).
using RasterDataSources, Zarr
T = ERA5{ECMWF,ARCO,Land}
source = getraster(T, :total_precipitation)
remote = Zarr.HTTPStore(source.url; headers=["Authorization" => "Bearer $key"])
ds = zopen(Zarr.CachingStore(remote, DirectoryStore(source.cache)))
tp = ds[layername(T, :total_precipitation)]

RasterDataSources.OnDemand — Type
OnDemand <: ERA5Store

Subsets cut on demand by the Copernicus Climate Data Store (CDS) API: downloads a regional monthly NetCDF subset rather than reading remotely from an ARCO Zarr store. Requests are queued server-side, so getraster submits a job and polls until done (seconds to hours). Served by ECMWF for ERA5{ECMWF,OnDemand} and ERA5{ECMWF,OnDemand,Land}.

Needs your CDS API token in ENV["RASTERDATASOURCES_ERA5_CDS_TOKEN"]. extent is WGS84 lon/lat; antimeridian-crossing extents are not supported.

Usage with getraster

getraster(T::Type{<:ERA5{ECMWF,OnDemand}}, [layer]; date, extent)

Arguments

  • layer: Symbol or Tuple of Symbol from layers(T), listed in ERA5, e.g. :total_precipitation. Each layer is a separate NetCDF file, holding the variable layername(T, layer).

Keywords

  • date: a Date, AbstractVector of Date, or a Tuple of start and end dates. One file is downloaded per month.
  • extent: an Extents.Extent bounding box, e.g. Extent(X=(143.0, 149.0), Y=(-44.0, -40.0)). It is expanded outward to the grid: 0.25° for ERA5, 0.1° for Land.
  • update: Bool, defaults to false. If true, re-download files even when a local copy already exists. Recent months are preliminary (ERA5T) and are later replaced.

Example

using RasterDataSources, Extents, Dates
getraster(ERA5{ECMWF,OnDemand}, (:temperature_2m, :total_precipitation);
    date=(Date(2020,1,1), Date(2020,12,31)), extent=Extent(X=(143.0,149.0), Y=(-44.0,-40.0)))
getraster(ERA5{ECMWF,OnDemand,Land}, :snow_depth;
    date=Date(2020,7,1), extent=Extent(X=(143.0,149.0), Y=(-44.0,-40.0)))
