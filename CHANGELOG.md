# Changelog

All notable changes to RasterDataSources.jl are recorded here.

## [v0.8.0] - Unreleased

### Breaking

- `NCEP` has new type parameters: a group, a reanalysis and a period. The group
  is `PressureLevels`, `Surface` or `SurfaceFlux`. The reanalysis is `1` or `2`.
  The period is `SixHour`, `Day` or `Month`, and defaults to `SixHour`. For
  example, `NCEP{PressureLevels,1,Day}` is daily pressure-level data from
  Reanalysis 1. The eight old category types, such as `DailyPressure`, are gone.
  So is the `dataset` keyword. ([#98], [#105])
- `NCEP` layers that do not exist on the server are removed: `:shum` from
  Reanalysis 2 `PressureLevels`, and `:lftx` from 6-hourly Reanalysis 2
  `Surface`. ([#123])
- `ERA5` has new type parameters: a provider, a store and an optional product,
  as in `ERA5{ECMWF,OnDemand,Land}`. Plain `ERA5` still works, and is the same
  as `ERA5{Google,ARCO}`, Google's public store. ([#111])
- `ERA5` files are now stored under `ERA5/<provider>/<store>`, so the Google
  store's cache moves from `ERA5/arco-era5-zarr` to `ERA5/Google/ARCO`.
  Existing local copies will not be found ([#121]). ([#111])
- `SLGA` now downloads from TERN, which needs a free API key in
  `ENV["RASTERDATASOURCES_SLGA_TERN_API_KEY"]`, from
  https://account.tern.org.au/createapikey. ([#116])
- `SLGA` layers `:der` and `:des` cover the whole profile and ignore `depth`.
  Passing their old depths, `"0-999cm"` or `"0-200cm"`, is now an error, and
  `depths(SLGA, layer)` is gone. ([#117])

### Changed

- `ERA5` layers now use the Climate Data Store's full variable names, with
  heights last, as in `:temperature_2m` and `:total_precipitation`. The old
  short names, such as `:t2m` and `:tp`, still work. ([#111])
- Monthly `NCEP` `:pr_wtr` now downloads `pr_wtr.eatm.mon.mean.nc`, which both
  reanalyses publish. ([#123])
- Compatible with HTTP.jl v2. Downloads use Downloads.jl. ([#112])

### Added

- `SILO`: daily Australian climate grids at about 5 km, from 1889 to the
  present. ([#104])
- `BARRA`: the Bureau of Meteorology's regional reanalysis for Australia. It
  covers `BARRAR2` at about 11 km and `BARRAC2` at about 4 km, at hourly, daily
  or monthly steps. `Static` gives the time-invariant layers, such as surface
  height. ([#107])
- `GRIDMET{Elevation}`: the elevation grid that gridMET uses. ([#103])
- `SoilGrids`: ISRIC's global soil property maps at 250 m, for six depths. It
  downloads the tiles that cover an `extent`. ([#117])
- `ERA5{ECMWF,OnDemand}` downloads ERA5 from the Climate Data Store for a chosen
  area, one file per layer per month. Requests are queued, so this can be slow.
  It needs a free API token in `ENV["RASTERDATASOURCES_ERA5_CDS_TOKEN"]`.
  ([#111])
- `ERA5{ECMWF,ARCO}` reads ERA5 directly from ECMWF's own cloud stores, with no
  queue. It is chunked for long time series over small areas, and uses the same
  token as `OnDemand`. ([#111])
- ERA5-Land, a finer 9 km version of ERA5 over land, as
  `ERA5{ECMWF,OnDemand,Land}` and `ERA5{ECMWF,ARCO,Land}`. ([#111])
- The `update` keyword downloads a file again, even when a local copy exists.
  `SILO` and `ERA5{ECMWF,OnDemand}` accept it. Use it for recent data, which
  these sources revise. ([#104], [#111], [#115])

### Fixed

- `NCEP` daily and monthly downloads, after NOAA moved them to the
  `.dailyavgs` and `.derived` datasets. Reanalysis 1 `:tcdc` now comes from
  `other_gauss`, which has every year, not only 2005. ([#123])
- `TerraClimate` downloads historical data from THREDDS, as the old server is
  down. ([#118])
- `GRIDMET{Elevation}` downloads the renamed `gridmet_elevation.nc`. ([#120])
- `GRIDMET` layers load as `Raster`s, using the variable names inside the
  NetCDF files. ([#109])
