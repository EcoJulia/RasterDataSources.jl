# Changelog

All notable changes to RasterDataSources.jl are recorded here.

## [v0.8.0] - Unreleased

### Breaking

- `NCEP` has new type parameters: a group, a reanalysis and a period. The group
  is `PressureLevels`, `Surface` or `SurfaceFlux`. The reanalysis is `1` or `2`.
  The period is `SixHour`, `Day` or `Month`, and defaults to `SixHour`. For
  example, `NCEP{PressureLevels,1,Day}` is daily pressure-level data from
  Reanalysis 1. The eight old category types, such as `DailyPressure`, are gone.
  So is the `dataset` keyword. ([#98], [#105])
- `ERA5` has new type parameters: a provider, a store and an optional product.
  Plain `ERA5` is still Google's public store. ([#111])
- `ERA5` layers now use the full variable names of the Copernicus Climate Data
  Store. Write `:total_precipitation`, not `:tp`. Names that start with a digit
  need `Symbol`, as in `Symbol("2m_temperature")`. ([#111])
- `ERA5` files are now stored under `ERA5/<provider>/<store>`. Existing local
  copies will not be found. ([#111])

### Added

- `SILO`: daily Australian climate grids at about 5 km, from 1889 to the
  present. ([#104])
- `BARRA`: the Bureau of Meteorology's regional reanalysis for Australia. It
  covers `BARRAR2` at about 11 km and `BARRAC2` at about 4 km, at hourly, daily
  or monthly steps. `Static` gives the time-invariant layers, such as surface
  height. ([#107])
- `GRIDMET{Elevation}`: the elevation grid that gridMET uses. ([#103])
- `ERA5{ECMWF,CDS}` downloads ERA5 from the Climate Data Store for a chosen
  area, one file per layer per month. It needs a free API token in
  `ENV["RASTERDATASOURCES_ERA5_CDS_TOKEN"]`. ([#111])
- `ERA5{ECMWF,ARCO}` reads ERA5 from ECMWF's cloud stores. It uses the same
  token. ([#111])
- ERA5-Land, a finer 9 km version of ERA5 over land, as
  `ERA5{ECMWF,CDS,Land}` and `ERA5{ECMWF,ARCO,Land}`. ([#111])
- The `update` keyword downloads a file again, even when a local copy exists.
  `SILO` and `ERA5{ECMWF,CDS}` accept it. Use it for recent data, which these
  sources revise. ([#104], [#111])
